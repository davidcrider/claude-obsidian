# AI Knowledge System

A self-organizing knowledge system for building and maintaining connected notes with AI assistance.

## Features

- Local-first knowledge management
- Source-cited pages and evidence tracking
- Connected knowledge graphs
- Transaction-based mutations
- Portable Markdown format

## Quick Start

```bash
git clone https://github.com/davidcrider/claude-obsidian.git
cd claude-obsidian
make help
```

## Structure

- `claude_obsidian/` - Core Python library
- `scripts/` - CLI tools and utilities
- `skills/` - Agent skills and workflows
- `templates/` - Vault templates
- `tests/` - Test suite
- `wiki/` - Knowledge base

## Development

```bash
make test
make validate
```
